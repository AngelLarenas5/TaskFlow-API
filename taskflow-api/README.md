# TaskFlow API

## Integrantes

##Descripción 
API REST para la gestión ágil de tareas personales y de equipo. Permite la creación, actualización, asignación y seguimiento de estados de tareas mediante endpoints ligeros y eficientes.

##Stack 
- Lenguaje: Python 3.11+
- Framework: FastAPI
- Control de versiones: Git & Github
- Gestion de proyecto: Trello
